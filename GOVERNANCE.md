# Governance

ARP is currently an early research project.

## Maintainer Model

The repository owner maintains the project direction, accepts pull requests, and manages releases. As the project matures, governance should move toward a lightweight technical steering group with representation from:

- AI agent developers
- Website operators
- Security researchers
- Standards contributors
- Domain extension maintainers

## Decision Process

Project decisions should prefer:

1. Interoperability
2. Security and privacy
3. Incremental deployability
4. Domain neutrality
5. Compatibility with Web standards

## Specification Changes

Substantive protocol changes should include:

- Motivation
- Compatibility analysis
- Security considerations
- Privacy considerations
- Examples
- Validation impact

## Extension Governance

Domain extensions should be versioned, reviewed, and tested. Breaking changes require a new major version.
