# ARP Support Articles

These articles explain ARP in the style of practical webmaster and developer documentation. They are meant for site owners, platform teams, CMS vendors, and agent developers who need to understand what ARP files mean and how to publish them.

## Start here

- [Introduction to ARP](INTRODUCTION_TO_ARP.md): what ARP does, what it does not do, and when a site should use it.
- [Create or update ARP files](CREATE_OR_UPDATE_ARP.md): step-by-step deployment guidance for a first ARP implementation.
- [Test and validate ARP](TEST_AND_VALIDATE_ARP.md): validation checks before exposing ARP to agents.

## Learn the pieces

- [ARP discovery file](ARP_DISCOVERY_FILE.md): how `/.well-known/arp.json` tells agents where to begin.
- [ARP resource files](ARP_RESOURCE_FILES.md): how resources, properties, relationships, and metadata are represented.
- [ARP actions and receipts](ARP_ACTIONS_AND_RECEIPTS.md): how agents discover executable operations safely.
- [ARP governance and limitations](ARP_GOVERNANCE_AND_LIMITATIONS.md): policies, authorization, rate limits, and the limits of voluntary protocols.
- [ARP extensions](ARP_EXTENSIONS.md): how domain-specific vocabularies evolve without changing the core protocol.
- [ARP schema reference](ARP_SCHEMA_REFERENCE.md): field-by-field guide to the current JSON Schema artifacts.

## Platform guides

- [ARP for CMS and platforms](ARP_FOR_CMS_AND_PLATFORMS.md): guidance for WordPress, Shopify, SaaS products, government sites, and static sites.
