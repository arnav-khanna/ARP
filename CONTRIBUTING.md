# Contributing

Thank you for contributing to ARP.

## Good First Contributions

- Improve examples
- Add references
- Clarify protocol language
- Review security assumptions
- Propose domain extensions
- Improve benchmark tasks
- Add migration case studies

## Pull Request Expectations

Please include:

- What changed
- Why it matters
- Compatibility impact
- Security or privacy considerations
- Examples, if applicable

## Writing Style

- Use precise protocol language.
- Prefer concrete examples.
- Distinguish normative requirements from research proposals.
- Avoid claiming measured results unless data exists.

## Research Contributions

For research-oriented changes, include citations where possible and label modeled estimates clearly.
