# Security Policy

ARP is a protocol proposal about agent interaction with websites. Security feedback is especially important.

## Reporting Security Issues

Please do not disclose exploitable issues publicly before maintainers have a chance to respond. Open a private advisory if available, or contact the repository owner.

## Areas of Interest

- Agent identity
- Authorization and delegation
- Signed receipts
- Prompt injection and misleading resource declarations
- Malicious resource declarations
- Replay attacks
- Downgrade attacks
- Signature/key rotation failures
- Data retention and training-use policy

## Current Status

This is a research draft, not production software. Do not treat the current protocol text as a complete security standard.
